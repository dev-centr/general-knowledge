= How-to Guides
:description: Task-oriented guides for common developer setup and workflow problems.

Task-oriented guides. Pick a guide when you already know what you want to do.

A how-to assumes the goal and the thing you are changing.
A tutorial would teach by building a small example from the start.
For AI-built sites, the how-to is xref:how-to/tighten-an-ai-built-site.adoc[Tighten an AI-built site] (the site already runs).
The from-scratch lesson is not written; the Tutorials landing says so.
Why the pages drift: xref:explanation/constrained-ai-web-design.adoc[Constrained AI web design].
Tokens: xref:reference/ai-site-design-contract.adoc[AI site design contract].

* xref:how-to/tighten-an-ai-built-site.adoc[Tighten an AI-built site] — lock tokens, drop nested cards, and prompt from one screenshot. The site already runs. Why it drifted: xref:explanation/constrained-ai-web-design.adoc[Constrained AI web design].

* xref:how-to/wsl-setup.adoc[Set up and manage WSL] — Enable WSL, pick a default distro, open WSL Settings.
* xref:how-to/flutter-setup.adoc[Set up Flutter tooling] — SDK bootstrap; community version bridges until an official Toolchain Control Plane exists (see Toolchain Management Pattern).
* xref:how-to/github-pages-custom-domain.adoc[GitHub Pages custom domain + Cloudflare HTTPS] — Grey-cloud for GitHub LE; poll Pages API; companion `scripts/check-gh-pages-https.nu`.

Cover `*.pages.dev` too. Why: xref:explanation/infrastructure/access-in-front-of-static-sites.adoc[Access in front of static sites].
* xref:how-to/finding-windows-internals-docs.adoc[Finding Windows internals documentation] — Learn / MSDN-shaped trees, MicrosoftDocs GitHub, search when wording differs.
