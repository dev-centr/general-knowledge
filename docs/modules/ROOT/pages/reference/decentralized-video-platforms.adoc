YouTube is convenient and fragile: accounts get limited, videos get age-gated or removed, and entire channels can vanish overnight. Dev-Centr curated watching therefore prefers:

. **Decentralized or federated host** (when a real mirror of the *same* work exists)
. **Publisher / project canonical page**
. **YouTube** (discovery)
. **Google Drive (or other org backup)** archival MP4 — not a substitute for a public host

Agents today can **web-search** Odysee / PeerTube / archive.org; there is **no first-class PeerTube or Odysee MCP** on this harness yet. If you need API-level search/upload, say so—we should add tooling rather than pretend YouTube is durable.

== Platform index (Dev-Centr notes)

[cols="1,1,2,2", options="header"]
|===
| Platform | Model | Good for | Caveats

| **https://joinpeertube.org/[PeerTube]**
| Federated (ActivityPub) + optional P2P playback; anyone can run an instance
| True self-host / community instances; Fediverse follow/comment
| Discovery is fragmented across instances; pick a reputable instance or self-host

| **https://odysee.com/[Odysee]**
| Consumer front-end historically tied to LBRY protocol / blockchain metadata
| YouTube-like UX with stronger “won’t delete my channel overnight” posture for some creators
| Corporate/product and protocol layers have shifted over time—verify current decentralization claims

| **https://lbry.com/[LBRY]** (protocol / apps)
| Blockchain metadata + P2P content addressing
| Protocol-level publishing; apps beyond one website
| UX and commercial wrappers changed; treat “LBRY” vs “Odysee” carefully in docs

| **https://d.tube/[DTube]**
| Steem/Hive-era crypto + IPFS-style distribution (evolving stack)
| Censorship-resistant upload narrative in the DailyCoin survey
| Ecosystem churn; verify liveness before linking as primary

| **https://www.thetatoken.org/[Theta]**
| Bandwidth-sharing / edge delivery network with tokens
| Delivery cost / gaming-adjacent streaming experiments
| More CDN-economics than “post a talk forever”

| **https://dlive.tv/[DLive]**
| Live-first, token tipping (Lino lineage)
| Live streams more than evergreen docs talks
| Not a default archival host for curated watching

| **https://3speak.tv/[3Speak]**
| Hive-network creator platform
| Long-form + citizen-journalist niches
| Smaller audience; confirm embed/permalink stability

| **https://livepeer.org/[Livepeer]**
| Ethereum-based transcoding / streaming network
| Infra for apps that need affordable live/VOD pipelines
| Protocol for builders; not a drop-in YouTube replacement UI

| **https://www.flixxo.com/[Flixxo]**
| BitTorrent + token economy (Netflix-shaped pitch in survey pieces)
| Distribution experiments
| Adoption unclear; verify before recommending

| **https://archive.org/[Internet Archive]**
| Centralized non-profit archive (not blockchain), but *durable* and citeable
| Snapshots of articles; sometimes video copies
| Not decentralized; still invaluable as a second shelf
|===

== How we cite videos in docs

Match the curated-watching table shape:

* Prefer a **decentralized URL in the primary “Watch” row** when it is the same work (same creator edit), not a reaction video.
* Always keep **YouTube** if that is where discovery happened.
* Always keep **Drive backup** for Dev-Centr-critical teachings (`inspirations/` on Ryan’s Drive today).
* If only YouTube exists, say so explicitly (as on xref:explanation/open-source/ecosystem-failures-and-successes.adoc[ecosystem failures and successes]) so the next editor knows to re-check Odysee/PeerTube later.
