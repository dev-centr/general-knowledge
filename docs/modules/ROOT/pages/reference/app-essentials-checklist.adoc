= App Essentials Checklist
:description: Printable checklist of software product essentials—identity, updates, packaging, pipeline, diagnostics—by artifact type.

Use with xref:explanation/architecture/software-product-essentials.adoc[Software Product Essentials]. Mark items that apply to your artifact type.

Interactive CentrMark copies: xref:how-to/product-essentials-checklists.adoc[Attach Product Essentials Checklists] — templates in `examples/product-essentials/`, instances under `.devcentr/checklists/`, progress in `<file>.cmk.checks/state.json5` (xref:reference/checklist-sidecar.adoc[sidecar schema]).

== Shared

* [ ] Marketing version defined
* [ ] Build id stamped at compile/CI time
* [ ] Channel stamped (`stable` / `beta` / …)
* [ ] Changelog + README entry points
* [ ] CI builds release artifacts on tags
* [ ] Checksums (and signatures when required) published
* [ ] Secrets redacted from logs/dumps by default
* [ ] Support doc: what users should attach
* [ ] Text files UTF-8 without BOM; `.editorconfig` `charset = utf-8`
* [ ] Encoding guard: machine-wide pre-commit hook + CI backstop reject mojibake and UTF-16 (xref:how-to/prevent-text-encoding-corruption.adoc[how-to])

== GUI

* [ ] About dialog with version + build id
* [ ] Help entry (docs + report issue)
* [ ] Debug dump button
* [ ] Open logs folder
* [ ] Desktop and/or mobile class template triaged
* [ ] Windows installer signed + uninstallable
* [ ] Auto-update or Store/winget/pkg updates on each desktop OS
* [ ] Stable signed update feed URL (marketing site) + versioned release asset
* [ ] Quit-first one-shot apply for direct installs (no long-lived update launcher)
* [ ] Channel-aware: no self-replace when Store/winget/Homebrew/pkg-managed
* [ ] Update status visible in About; honor managed disable/pin

== Delivery-class auxiliaries

Prefer the printable xref:reference/auxiliary-features-checklist.adoc[Auxiliary features checklist] for desktop / web / mobile Band A–C rows.

== CLI / TUI

* [ ] `--version` includes build id
* [ ] `doctor` or `debug-dump`
* [ ] Package manager or documented install
* [ ] Self-update disableable if present
* [ ] TUI: in-app About/help keybind

== Library

* [ ] Registry publish on tag
* [ ] SemVer policy + changelog
* [ ] Support matrix documented
* [ ] Migration notes on breaks

== Game

* [ ] Client + content versions visible
* [ ] Crash/log export
* [ ] Store/channel update verified

== Service

* [ ] `/health` or `/version` includes build id
* [ ] Auth-gated diagnostics
* [ ] Rollback-tested deploy
* [ ] Runbook linked
