Developers and designers choosing visual direction—or handing an AI coding agent a concrete visual reference—need real examples that hold up under inspection.
This catalog tracks websites whose UI design is considered worth studying, paired with the date each site was added and a Wayback Machine snapshot from that period.

Sites redesign frequently.
A recommendation written today can point to a completely different layout a year later, so every entry records at least the date it earned inclusion and a direct historical archive link in the page source.

== How entries are recorded

Every entry in the table follows three rules so the catalog stays useful years later:

* **Date added (`YYYY-MM-DD`) is required.** Always record the calendar date the site was added so readers know which version of the site was judged exemplary.
* **Include a direct Wayback Machine archive link in the source.** Link to the closest HTTP 200 snapshot on or before the date added (`https://web.archive.org/web/<timestamp>/<url>`). If no recent snapshot exists yet, save one on the Wayback Machine first or link the capture calendar (`https://web.archive.org/web/*/<url>`) until a dated snapshot is captured. Linkinator (`v0.1.13+`) skips `archive.org` and configured archive providers automatically; for any other link that should opt out explicitly, use `role=linkinator-skip`.
* **Keep both live and archived links.** On the published docs site, the link:https://github.com/antora-supplemental/linkinator[Linkinator] extension automatically attaches a Wayback Machine archive lookup button to outbound links on hover. Keeping an explicit dated archive URL in the AsciiDoc source ensures people and AI agents working locally in a repository checkout—without the rendered site or Linkinator—can still jump straight to the exact historical design.
