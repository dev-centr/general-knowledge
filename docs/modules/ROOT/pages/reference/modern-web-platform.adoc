Use native, Baseline web platform primitives before reaching for custom JavaScript widgets or `<div>`-soup.
Rather than hand-maintaining an internal checklist of modern HTML and CSS features, link directly to MDN and install the browser-vendor-maintained guidance packages below across harnesses.

== Canonical HTML reference

* **link:https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements[MDN HTML Elements Reference^]** — authoritative index of all HTML elements, semantics, and live Baseline browser support.
* **link:https://web.dev/baseline[Web Platform Baseline^]** — W3C WebDX / cross-browser availability status (*Newly Available* vs. *Widely Available*).

High-value native HTML primitives agents commonly overlook in favor of JS wrappers:

[cols="1,3",options="header"]
|===
| Primitive | Use instead of

| `<dialog>` + `showModal()`
| Hand-rolled modal overlays, focus traps, and `Escape` listeners

| `popover` + `popovertarget`
| Custom dropdown/tooltip click-outside and z-index managers

| `<details>` / `<summary>` (with shared `name` for exclusive accordions)
| Custom accordion scripts and `aria-expanded` toggles

| `<search>`
| Generic `<div role="search">` wrappers

| `<datalist>`, `<output>`, `<meter>`, `<progress>`
| Ad-hoc autocomplete lists and numeric/status `<div>` bars

| `inert` attribute
| Manual `tabindex="-1"` loops to disable background subtrees
|===

== Recommended cross-harness agent tooling

Prefer these vendor-stewarded packages over writing and maintaining a private modern-web skill:

[cols="1,1,2,2",options="header"]
|===
| Tool | Maintainers | What it gives agents | Cross-harness install

| **link:https://github.com/GoogleChrome/modern-web-guidance[Modern Web Guidance]** (`GoogleChrome/modern-web-guidance`)
| Google Chrome, Microsoft Edge, Mozilla, and MDN contributors
| Portable Agent Skills steering coding agents toward Baseline HTML/CSS/JS primitives, View Transitions, Container Queries, Popover/Dialog APIs, and Core Web Vitals
| `npx modern-web-guidance@latest install` (or `npx skills add GoogleChrome/modern-web-guidance`; also available via harness plugin marketplaces such as Antigravity Marketplace, Claude Code, and GitHub Copilot CLI)

| **link:https://mcp.mdn.mozilla.net/[MDN MCP Server]** (`https://mcp.mdn.mozilla.net/`)
| Mozilla (MDN)
| Live Model Context Protocol access to MDN Web Docs and Browser Compatibility Data (BCD) so agents verify feature support instead of guessing from training cutoffs
| Add as an HTTP MCP server (`https://mcp.mdn.mozilla.net/`) in any MCP-capable harness (Antigravity, Cursor, Claude Code, Codex, VS Code, Zed). Pass `X-Moz-1st-Party-Data-Opt-Out: 1` to opt out of first-party analytics.
|===
