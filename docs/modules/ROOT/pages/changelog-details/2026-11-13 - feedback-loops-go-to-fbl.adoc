== Feedback loops go to fbl

xref:reference/email/cloudflare-email-routing-and-sending.adoc#operator-addresses[Operator addresses] keeps `abuse@` as the public contact a person reads.

Automated ARF feedback loops go to `fbl@`. That address is not the published public contact. The detector reads it. Gmail does not send per-message ARF, and Postmaster Tools is not pointed at `abuse@`. A spam complaint still does not remove the `mailer-daemon` inbox whitelist.
