== Feedback Loop (FBL) copies

xref:reference/email/cloudflare-email-routing-and-sending.adoc#operator-addresses[Operator addresses] keeps `abuse@` as the public contact a person reads.

A Feedback Loop (FBL) sends its automated copy to `fbl@`. That address is not the published public contact. The detector reads it. Gmail does not send these per-message copies, and Postmaster Tools is not pointed at `abuse@`. A spam complaint still does not remove the `mailer-daemon` inbox whitelist.
