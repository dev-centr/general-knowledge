== Why

Mermaid 11 writes node colors as inline `fill:… !important` / `stroke:… !important`.
Earlier Themed SVG pins rewrote some stylesheet rules but left light-palette paints that
did not track the site or `prefers-color-scheme` dark palette, so labels and boxes could
lose contrast.

== Change

* Pointed the diagram toolchain at `@dev-centr/themed-svg` 0.2.3 and `@dev-centr/mermaid-svg-css-vars` 0.1.3 from the registry.
* Added `#my-svg .<class> tspan` bindings so Mermaid classDef text fills use theme variables (later stylesheet, same specificity).
* Regenerated all canonical diagram adaptive and host SVGs via `pnpm run diagrams:build`.
* Updated diagram validation for the 0.2.x contract (`height` omitted; package pins; tspan bindings).
* Node rects and labels now use `var(--themed-svg-diagram-…, …) !important` instead of bare light hex.
