== Why

The Reference reliability PlantUML sequence still failed in hub dark mode:
classes sat on parent `<g>` nodes while fills/strokes lived on children, and
notes/dividers had no semantic classes.

== Change

* Depend on `@dev-centr/plantuml-svg-css-vars` **v0.1.1**.
* Rebuild `label-as-wire-break` adaptive + host SVGs and theme manifest.
