== Summary

AI agents running commands in Windows PowerShell 5.1 corrupted text in InstaLay twice: a garbled `release.yml` that GitHub rejected (introduced in `8b35a27`, fixed in `b7dd746`) and changelog dashes garbled since `f45ceda` (2026-09-10).
This release documents the mechanism, the restriction on agents, and the layered guard: a machine-wide pre-commit hook as the primary layer, CI as the backstop.
