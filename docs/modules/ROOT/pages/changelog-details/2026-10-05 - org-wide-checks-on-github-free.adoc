== Summary

All 15 organisations behind Dev-Centr are on GitHub Free, where organisation rulesets answer 403 "Upgrade to GitHub Team". The encoding guard therefore ships as a per-repository caller of one reusable workflow. This release turns that workaround into its own page, since most projects will not pay for GitHub Team until they are a business.
