== Local-first git and CI

Added xref:how-to/local-first-git-and-ci.adoc[Local-first git and CI]: commit locally and push on request (no blind auto-push timer), use a daily unpushed-commits reminder, stack dependent work on one branch instead of waiting on pull requests, and split fast push/PR checks from heavy `v*` / `workflow_dispatch` package builds.

The page includes a GitHub Actions YAML example (`concurrency` with `cancel-in-progress: true`, `retention-days: 1` for release handoff artifacts, `retention-days: 3` and `if: failure()` for debug artifacts) and explains that the organization and repository retention cap now also expires checks, workflow runs, and commit statuses.
