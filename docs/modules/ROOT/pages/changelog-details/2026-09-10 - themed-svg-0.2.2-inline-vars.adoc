== Why

Mermaid 11 writes node colors as inline `fill:… !important` / `stroke:… !important`.
`@dev-centr/themed-svg` 0.1.1 left those concrete light-palette values in place, so host CSS variables could not override node fills.

== Change

* Pointed the diagram toolchain at `@dev-centr/themed-svg` 0.2.2 and `@dev-centr/mermaid-svg-css-vars` 0.1.3 from the registry.
* Regenerated all canonical diagram adaptive and host SVGs via `pnpm run diagrams:build`.
* Host node rects now use `fill:var(--themed-svg-diagram-…, …) !important` instead of bare light hex with `!important`.
