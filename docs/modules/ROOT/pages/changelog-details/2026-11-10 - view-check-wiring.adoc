xref:explanation/architecture/view-check.adoc[View-check] tells a product how to call the command in link:https://github.com/dev-centr/view-check[dev-centr/view-check].

* The host passes `--profile`, `--snapshot`, and, when a view breaks a rule on purpose, `--exceptions`.
* The exception file lives with the view. It is not an `excludes` line in the profile ledger.
* The page links to HCI Nerdz for the sentences a person agrees to, and does not restate them.
