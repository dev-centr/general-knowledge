= 2026-08-12 — Finish GitHub IdP setup (enterprise-setup 500)

Creating a GitHub identity provider (dashboard Save, or `POST /access/identity_providers`) does not complete GitHub consent. Cloudflare’s GitHub how-to calls the missing click **Finish setup** (orgs/teams + email, read-only), then **Test**.

Agents that create the IdP via API may get a `messages` URL:

`https://<team-name>.cloudflareaccess.com/cdn-cgi/access/enterprise-setup/<opaque>`

That URL is one-shot (not returned on later `GET`) and can fail with Cloudflare **error 500** / Internal server error (a Ray ID). Fallback: dashboard Finish setup / Test, or the first GitHub login on the Access application.
