== Four layers (one stack)

. *Content-addressed identity (CAS)* — same bytes (or same semantic unit) keep a stable id when the label moves.
. *Mutable pointer* — human name resolves to the current edition when content updates.
. *Reverse consumers* — who still holds a label (`CONSUMERS.md` today; graph reverse edges tomorrow).
. *Absorb layer* — redirects and aliases on today’s classical web (see xref:explanation/internet-architecture/reliability/near-term-absorb.adoc[Near-term absorb]).
